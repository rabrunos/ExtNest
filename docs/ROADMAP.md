# Roadmap

## v0.1 — protótipo
- Native Messaging em Python.
- GitHub via PAT.
- seleção manual de repositórios.
- clones no AppData.
- detecção de versão.
- bridge de configurações.
- nuvem via pasta sincronizada OneDrive/Google Drive.

## v0.2
- helper `.exe` único;
- prompt de restore após instalação;
- commit/push pelo painel;
- reparar instalação local;
- importar lista da nuvem em PC novo.

## v0.3
- GitHub OAuth Device Flow;
- diff antes de atualizar;
- botão Abrir no VS Code.

## v0.4
- OAuth direto OneDrive;
- OAuth direto Google Drive;
- migração entre provedores;
- criptografia opcional de backups sensíveis.

## Distribuição
- ExtNest: Edge Add-ons + Chrome Web Store.
- Extensões gerenciadas: privadas, GitHub + AppData + Load unpacked.

## Fora de escopo
- publicar as extensões gerenciadas em lojas;
- CRX privado para extensões gerenciadas;
- atualização silenciosa sem ação do usuário.
